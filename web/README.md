# Project Memoria Web

This is the Milestone 0 foundation for Project Memoria.

## Stack

- Next.js App Router
- React 19
- TypeScript
- Tailwind CSS v4
- shadcn/ui
- next-themes
- ESLint
- Prettier

## Scripts

```bash
npm run dev
npm run lint
npm run build
npm run format
```

## Scope

Milestone 0 owns only the project foundation, theme wiring, placeholder routes,
folder skeleton, and data-client boundary stub. Feature behavior, data model,
agent runtime, authentication, graph rendering, and database integration are
deferred to later milestones.
